| **几何与网格场**              | 读取 `.inp` 中的 TET4 单元，构造固定四面体网格；热场和力学场共用同一个 `Mesh(points, cells, ele_type="TET4")`。                                                                           | TET4 为线性单元，单元内应变/应力近似常值；对熔池边界、温度梯度、应力峰值不敏感。                                                      | 增加网格分辨率控制：熔池区局部细化、扫描路径附近细化、或者至少提高 `scan_steps_per_layer`；长期可考虑 TET10 / HEX / 局部 AMR。                                                      | Abaqus AM 框架允许任意 FE 网格，并通过路径-网格相交追踪材料添加和热源；文献中也强调熔池附近需要细网格和约 1 ms 级时间步才能捕捉高梯度。([Dassault Systèmes][1])                                                                                                 |
| **时间步 / 工艺步场**          | 通过 `StepState` 记录 `mode`、layer、hatch、scan index、laser center、laser power、laser switch、dt 等；支持 raster 和 path-file 两种路径。                                       | 当前 `mechanics_every` 是采样式力学求解，热场每步算，力学不一定每步算；如果设置为 20，只能展示更多层内细节，但不改变热源路径分辨率。                    | 增加工艺事件类型：laser_on、laser_off、jump、recoat、dwell、cooling、remelt、solidification；增加 `mechanics_offset`，使输出可以落在每条 hatch 末端而非起点。                 | Abaqus 使用 `Event Series` 表达随时间和空间变化的材料沉积路径、激光路径和功率；Ansys 也把 AM 过程抽象成层层激活、热历史再映射到结构求解。([VT 软件文档][2])                                                                                                    |
| **瞬态热传导场**              | 当前热场残差相当于：(\rho(c_p+c_L)(T^{n+1}-T^n)/\Delta t-\nabla\cdot(k\nabla T)-q=0)。代码中 `heat_flux = k∇T`，`heat_capacity` 中包含 (\rho c_\text{eff}(T-T_\text{old})/dt)。 | 是纯热传导模型，没有显式流体速度场，也没有熔池内部对流。对宏观温度趋势可以用，但熔池形状需要校准。                                                | 增加热场诊断量：冷却速率 (\dot T)、温度梯度 (\nabla T)、最大历史温度、液相分数；如果后续做更真实熔池，可加入等效增强导热或热流体模型。                                                             | Mukherjee 等指出残余应力计算的精度强依赖瞬态温度场质量；他们用热传导-流体流动模型提供温度场，再做热-力计算。([matse.psu.edu][3])                                                                                                                       |
| **激光热源场**               | 当前是体积高斯 + 单边指数深度衰减：(\frac{2P_\text{abs}}{\pi r_b^2 d_s}\exp(-2r^2/r_b^2)\exp(-d/d_s))，并乘以 `laser_switch` 和 `active`。                                         | 不是标准 Goldak 双椭球，也不是表面通量；`source_depth` 是人为穿透深度。若 `laser_power` 被调得极大，可能是在补偿单位或热源尺度问题。            | 增加热源类型枚举：`surface_gaussian`、`volumetric_gaussian`、`Goldak`、`conical`、`uniform_box`；增加吸收率 (\eta(T,\text{powder/solid},\theta))；添加能量守恒检查。   | Abaqus AM 支持集中移动热源、Goldak 分布和均匀体积分布，并通过 event series + table collection 定义路径、功率和吸收系数。([VT 软件文档][2])                                                                                                    |
| **热边界：对流 / 辐射**         | 现有表面热流：(q=h(T-T_\infty)+\epsilon\sigma(T^4-T_\infty^4))。代码中 `surface_flux()` 对 fixed exposed/walls 施加对流和辐射。                                                  | 表面集合基本是静态外表面，不是真正随打印过程演化的自由表面；当前配置里 `emissivity=0` 时辐射完全关闭。                                      | 新增 **动态自由表面**：当前层表面、侧壁、被覆盖面；被后续材料覆盖后取消对流/辐射；熔池表面可加入蒸发热损失。                                                                                 | Abaqus/3DS AM 框架强调 continuously evolving convection and radiation surfaces；AM_Thermomechanical_Solver 也用 `surface_birth` 判断当前 active surface，并只在 active surface 上施加高斯热流、对流和辐射。([Dassault Systèmes][1]) |
| **移动前沿热损失近似**           | 代码有 `front_surface_loss_h`，以体积带形式近似 active/inactive build front 上的对流/辐射损失。                                                                                   | 这是人为体积损失，不是真正的内部边界面；可能导致热损失位置和真实自由表面不一致。                                                         | 如果做熔池，建议优先做动态自由表面，而不是继续扩大 front-loss 体积项；front-loss 可保留为调试或等效校准项。                                                                         | 商业 AM 框架通常通过路径-网格相交和 evolving surface 来处理加热/冷却边界，而不是简单固定表面或体积近似。([Dassault Systèmes][1])                                                                                                               |
| **材料热物性场**              | 当前支持常数或 CSV 表：(k(T), c_p(T), E(T), \alpha(T), \nu(T), \sigma_y(T), H(T))。`PropertyTable` 用 `np.interp` 插值。                                                   | 你的上一轮 `used_config` 中很多表为 `null`，所以实际运行是常数材料；这会削弱高温软化和 TC4 特征。                                   | 给 TC4 建立完整材料表：(k(T), c_p(T), \rho, E(T), \alpha(T), \nu(T), \sigma_y(T), H(T))；粉末和固体分开定义。                                                 | Ansys AM 文档把 build material melting temperature、powder thermal conditions、build-environment thermal BC 等作为 AM 专用命令/对象；Abaqus AM 也使用 Property Table 表示温度/场变量依赖参数。([Ansys Help][4])                      |
| **粉末 / 空洞场**            | 当前 `powder_mode` 可选 `powder` 或 `void`；`void` 下未激活区用极小热导/密度因子近似；`powder` 下使用 `rho_powder, cp_powder, conductivity_powder`。                                    | `void` 更像数值 birth-death 技巧，不是真实粉床；若是 LPBF，粉末仍有导热、热容、吸收率和辐射传热。                                    | 定义 `powder_state`：unmelted powder、partially fused、solidified；粉末 (k_p(T,\phi))、(\rho_p)、(c_{p,p})、吸收率 (\eta_p)。                            | Ansys 文档说明粉床周围未熔粉末可不用显式建模，而可用固体-粉末界面的简化对流边界表示热损失。([Ansys Help][4])                                                                                                                                     |
| **元素激活 / 材料添加场**        | 当前激活逻辑是 build front 推进：只要单元质心位于当前 front 以内，就激活；substrate/support 初始激活。                                                                                       | 是层前沿激活，不是 toolpath footprint 激活；扫描尚未经过的同层区域可能过早参与力学承载。                                           | 改为路径足迹激活：根据 laser center、beam radius、hatch spacing、layer thickness 和 `laser_on` 判断单元出生；增加 partially filled volume fraction。               | Abaqus 使用 progressive element activation 和材料沉积 event series 自动按沉积序列激活单元；Ansys 对 LPBF 采用 layer activation，对 DED 可用 G-code 激活沿路径的 element clusters。([VT 软件文档][2])                                        |
| **相变 / 熔池状态场**          | 当前有 `material_state`: inactive/powder、active solid、mushy、liquid、substrate、support；潜热用 apparent heat capacity：(c_L=L/(T_l-T_s)) 只在 solidus-liquidus 区间启用。     | `material_state` 主要是输出标签；液态区并不自动失去力学承载能力。潜热用 `T_old` 判断，且没有液相分数历史。                               | 新增 (f_l(T))：0/线性/1；输出 `liquid_fraction`、`melt_pool_flag`、`mushy_flag`、`solidified_flag`、`remelt_flag`；用焓法 (H=\int \rho c_p dT+\rho Lf_l)。 | AM_Thermomechanical_Solver 读取 solidus、liquidus、latent heat，并在积分点给 (\rho L/(T_l-T_s)) 加入等效热容；3DS/Abaqus 论文将 raw-liquid-solid 状态、熔化、气化、凝固和固态相变作为内部状态变量框架。([GitHub][5])                                   |
| **熔池流动物理场**             | 现有代码没有速度场、压力场、自由液面、表面张力、Marangoni、recoil pressure。                                                                                                           | 如果只靠热传导，熔池宽深比和峰值温度需要强校准；不能预测 keyhole、飞溅、流动导致的熔池形态变化。                                             | 初期可不直接上 CFD，而先用等效增强导热或 Goldak 参数校准；长期可新增 Navier–Stokes、VOF、表面张力、Marangoni、recoil pressure、蒸发热损失。                                          | laserbeamFoam 是开源 VOF 熔池/激光-基体相互作用求解器，包含熔化/凝固、recoil pressure、Marangoni、潜热、浮力、固化动量阻尼和 ray tracing。([GitHub][6])                                                                                        |
| **热-力耦合方式**             | 当前是一向顺序耦合：先求热场 (T)，再把 (T) 转到力学积分点求 (dT)、位移、应力。主循环里先 `T_new = solver(thermal)`，再构造 `mechanics_params`。                                                        | 没有力学变形反过来影响热源、接触、导热或几何；对宏观残余应力可接受，但对熔池变形/自由表面无效。                                                 | 保持弱耦合用于宏观应力；熔池级别若需要流固热耦合，则另建局部子模型或多尺度模型。                                                                                                  | Ansys 明确说明 AM Process Simulation 中 thermal 和 structural physics 大多弱耦合，先逐层热分析，再把温度结果用于结构分析。([Ansys Help][4])                                                                                            |
| **热应变场**                | 当前小变形热应变：(\epsilon_{th}=\alpha(T)\Delta T I)，其中 (\Delta T=T-T_\text{activation})。                                                                            | 若 (\alpha) 随温度变化，用 (\alpha(T)(T-T_0)) 不如积分 (\int_{T_0}^{T}\alpha(\theta)d\theta) 严谨；重熔后参考温度没有重置。 | 增加积分型热应变：(\epsilon_{th}=[\int_{T_{ref}}^{T}\alpha(\theta)d\theta]I)；增加 `stress_free_temperature`，在凝固/重熔后更新。                               | Ansys Additive Print 的 thermal strain 逻辑把材料开始凝固作为热应力开始积累的关键点，并在热历史求解后做结构应变/应力计算。([创新空间][7])                                                                                                            |
| **弹性 / 热弹性力学场**         | 当前总应变 (\epsilon=\frac12(\nabla u+\nabla u^T))，弹性应力 (\sigma=\lambda tr(\epsilon_e)I+2\mu\epsilon_e)。                                                          | 小变形、各向同性、无相变应变、无组织各向异性；TC4 AM 件可能存在纹理和方向性。                                                       | 短期加入 (E(T), \nu(T), \alpha(T))；中期加入各向异性/正交各向异性；相变模型中加入 transformation strain。                                                             | 3DS/Abaqus 相变框架把物理状态和相体积分数作为场变量，可进一步用于热学/力学属性计算。([Dassault Systèmes][1])                                                                                                                               |
| **塑性 / 残余应力历史场**        | 代码有简化 J2 plastic：用 (\sqrt{3/2s:s}) 判断屈服，超过屈服后缩放偏应力，并更新 `eqp_old`。                                                                                            | 当前是 stress clipping / 近似 return mapping；只存等效塑性应变，不存完整塑性应变张量；没有一致切线、退火、熔化重置。                      | 增加完整 J2 return mapping、塑性应变张量 (\epsilon^p)、硬化变量、温度相关 (\sigma_y(T))、高温 anneal reset、液化/重熔 reset。                                           | AM_Thermomechanical_Solver 的 `constitutive_problem()` 在积分点做 trial stress、屈服判断、塑性修正，并预留 `T_anneal`：超过退火温度时将累积塑性应变和硬化变量置零。([GitHub][8])                                                                  |
| **熔池力学承载约束**            | 当前液态/糊状状态没有直接削弱 `E` 或 deviatoric stress；active 区仍按固体材料参与力学，除非你给 (E(T)) 或 yield 表。                                                                            | 可能在 liquid 区出现不真实高 von Mises；残余应力历史可能跨过熔化阶段继续保留。                                                 | 用 (f_l) 修改力学：(E_\text{eff}=E_s(1-f_l)^m+E_{floor})，(\sigma_{y,eff}=\sigma_y(1-f_l)^n)；液态区偏应力接近 0；凝固时重设 (T_{ref})。                         | 文献中的相变框架明确包含 raw/liquid/solid 物理状态切换；laserbeamFoam 也通过 momentum damping 描述凝固区流动阻尼。([Dassault Systèmes][1])                                                                                             |
| **边界 / 夹具 / 基板场**       | 热边界底部可固定温度；力学上底面三向位移全固定。释放时可切换成 anchor 型约束。                                                                                                                  | 全固定底面会放大约束应力；真实打印存在基板厚度、夹具刚度、支撑、切割释放、接触导热。                                                       | 增加 substrate/support 实体厚度，夹具等效弹簧或局部固定，热接触导热，打印后切割/释放步骤。                                                                                   | Ansys 输出 on-plate residual stress/distortion，并区分仍附着在 baseplate 的最终应力和构建过程最大应力；Ansys AM 还把 supports 作为正交均匀化实体处理。([Ansys Help][9])                                                                       |
| **应力后处理 / von Mises 场** | 你已经改成积分点应力 (\sigma_{quad}) → 积分点 von Mises → `von_mises_mean/max/p95`，并用 `JxW` 做加权平均，同时提供 nodal recovered field。                                             | nodal recovery 仍是 cell-to-node 简单平均，不是严格 L2 projection / SPR；TET4 下 mean/max/p95 可能差别很小。         | 增加 `stress_quad` / `vm_quad` 原始积分点输出；做 volume-weighted nodal recovery、L2 projection、mesh convergence；论文展示固定色标并输出差值场。                      | AM_Thermomechanical_Solver 的 `transformation()` 用积分点量和 `ele_detJac` 权重恢复到节点，类似你现在要走的方向。([GitHub][8])                                                                                                   |
| **过程尺度简化 / 大模型策略**      | 当前逐步热场 + 间隔力学求解；可以通过 `mechanics_every` 控制力学成本。                                                                                                               | 如果全路径全力学步都求，成本较高；如果力学步太稀，扫描内应力细节不足。                                                              | 建议形成双层策略：展示用 `mechanics_every=20`；验证局部细节用 `mechanics_every=1` 小模型；整件工程用 super-layer / inherent strain / assumed strain。                   | Ansys 宏观 AM Process Simulation 使用 super layers、layer-by-layer addition、大时间步等抽象，并明确不捕捉局部平滑热循环细节；其目标是宏观应力/变形趋势。([Ansys Help][4])                                                                         |
| **验证 / 校准场**            | 代码会生成 calibration notes，但目前没有自动校准闭环。                                                                                                                         | 目前热源、吸收率、source depth、材料参数可能通过人为调参匹配，缺少能量守恒和熔池尺寸校准。                                              | 增加校准目标：melt pool width/depth、peak T、cooling rate、residual stress、distortion；输出能量输入/热损失/内能变化。                                              | Mukherjee 等强调残余应力计算依赖准确瞬态温度场；3DS/Abaqus 相变论文也用温度、熔池尺寸、相分数实验数据验证模型。([matse.psu.edu][3])                                                                                                                 |
