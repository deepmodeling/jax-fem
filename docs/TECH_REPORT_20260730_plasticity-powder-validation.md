## 1. 起点:v05 塑性历史(5eff022,2026-07-10)

在 v03/v04 热-弹性框架上引入 J2 塑性历史(等效塑性应变 eqp 追踪、
边界应力后处理、126 行单测)。此时的模型状态:TET4 网格、粉末不参与力学、
逐层沉积的悬空跨无侧向支撑。后续三周的全部修正围绕两个缺陷展开:
**粉末不承载**与**线性四面体的体积锁定**——前者是物理缺失,后者是
离散病态,二者纠缠在同一个症状里(残余变形预测杂乱不可复现)。

## 2. 粉末约束:两代实现与它带来的修正(重点)

### 2.1 症状与归因

Kaess 2023 悬臂 code-to-code 基准(250 W / 0.85 m/s / 10×30 µm 层)暴露:
过夜运行的 release 挠度结果杂乱,幅值和符号均不可复现。金标裁决
(2dc73e2)定量确认锁定 TET4 的 release 位移可复现带宽 **±100%**,
且同代码双运行 u 分叉 4.2×10⁻⁴——症状由三个因素叠加:悬空跨无约束、
TET4+J2 体积锁定、多线程 MKL 舍入噪声经病态刚度放大。

### 2.2 第一代:粉末床侧向 Winkler 约束(04d5025,2026-07-15)

对已打印材料的外侧面施加仅水平分量的 Winkler 弹簧(`--powder-mechanics-bc
elastic`,k_p 默认 1e9 Pa/m,**注册为未标定旋钮**)。面掩码逐力学步跟随
打印状态;release 问题不含该面,"释放=去粉"语义自动成立。验证:8 项新单测
+91 项回归;E2E 对照确认建造期侧向位移受约束、线弹性 release 与无粉末
逐位一致。定位:轻量、非侵入,但只约束表面,不承载体载。

### 2.3 第二代:弱固体粉末(c475f7e,2026-07-21)——精度修正的主力

按 Kaess 论文 Sec 2.2 语义,墙间隙剖分为 POWDER 单元集(34,560 tets),
粉末作为弱固体参与力学(E=10 GPa、σy=1 MPa),release 时与锯切同机制去粉。

**精度修正(同工况直接对照,150 °C 板温)**:

| 配置 | 前端挠度 | 说明 |
|---|---|---|
| 无粉末约束 | −49.8 µm | 悬空跨自由下垂,方向与论文相反 |
| 弱固体粉末 | **−3.6 µm** | **幅值缩小到 1/14** |
| Kaess 论文参考 | +14 µm(向上) | 符号仍未翻转 → 触发下一层归因 |

这一步证实悬空跨是"过夜挠度杂乱"的主因;残余的符号错误则把调查引向
离散层——**这是粉末约束的第二重价值:它把物理缺失从症状中剥离,让
体积锁定第一次以教科书指纹裸露出来**(约束态 von Mises 健康、钳在屈服附近;
静水压力棋盘格振荡,层内 std ≈1870 MPa,为偏应力变化的 18–19 倍,单点
σxx 达 ±12 GPa;弱固体与无粉末运行锁定严重度相同 18.5x/19.5x → 病灶
不在粉末,在单元)。

**数值稳定性修正(同提交)**:H=0 理想塑性使 3 万个屈服粉末单元的切线
半正定,Newton 停滞且不随增量切割改善;引入 `--powder-solid-hardening 1e7`
(E 的 0.1%,注册为正则化偏差项)后,完整算例增量切割次数 **9 → 0**。
粉末约束不只是精度项,也是收敛性项。

### 2.4 锁定修复收口:HEX8+B-bar(ecac731,2026-07-21)

TET4 上 F-bar/B-bar 是恒等操作(常应变单元),正解 = 力学网格换 HEX8+B-bar,
同时消除与 Abaqus C3D8 参考解的最大网格身份差(C3D8 内建选择性缩减积分
= B-bar)。锁定指纹(层内去均值 p-std/vm-std,健康值 O(1)):

| 配置 | 指纹 |
|---|---|
| HEX8+B-bar(2 层冒烟,29,568 单元逐单元与论文同构) | **0.95** |
| 锁定 TET4 同帧基线 | 1.91 |
| 锁定 TET4 十层 cooling / release | 8.40 / 9.31 |

配套:B-bar 经 universal kernel 实现(试探/检验一致,切线 jacfwd 自动,
稀疏模式不变 → PARDISO 模式缓存无恙);HEX8 强制 quadrature≥2(单点=沙漏);
零能模式单测(dd7b99e)。粉末网格升级为 c3d8 powder-margin 全奇偶网格
(48×28×22 = 29,568 单元,含侧向边距,消除第二代的"边距未剖分"偏差)。

## 3. 运算速率修正

粉末约束把力学问题做大(粉末单元全刚度装配,+17,728 单元),HEX8 又比
TET4 每单元贵——速度工作与精度工作是同一条时间线上的攻防:

| 节点 | 措施 | 实测收益 | 数值影响 |
|---|---|---|---|
| ac4fa70(7-15) | PARDISO 多核直接法后端 | solver **7.1x** | VTU 逐位一致 |
| 664d675(7-17) | G1 三件套:温度钳位+自动增量切割+热容质量集总 | 集总 ~2.4x/步,切割 9→1 | 激活下冲精确归零(T_min 逐位=板温) |
| 94e31ab(7-17) | PARDISO phase23(符号分析一次+数据不变回代捷径) | solver 68→50 ms;**真实一层 wall 37.7→7.2 min(5.2x)**,3936 解仅 2 次符号分析 | T/eqp 逐位一致,u 在力学容差带内 |
| a383abb/1f971c7(7-22/23) | Abaqus 式双判据收敛验收(opt-in)+严格残差保护 | 消除 j2 停滞带死循环(停滞底 ~2e-5,生产容差 5e-5) | 判据显式化,非精度损失 |
| 88d33aa(7-22) | r3 力学装配缩减 + PARDISO setup 缩减 | 中等算例力学链进入 1.9–3.1 h 预算带(384 步全流程) | — |

**负结果(同样入档,划定适用边界)**:GPU 平台切换在 3 万单元规模负收益
(120 s/步,GPU 利用率 4%)——GPU 留给 197k+ 生产网格(AM-Sim lane,装配
3.4x);MKL 2026.1 的 fp32 kernel 慢 10–30x → fp32ir 阶梯在当前 MKL 版本
不可用;397k 3D 超弹性 PETSc 反超 6x。

当前规模基线:2 层 HEX8 冒烟 21,264 s / 2,273 步 ≈ 9.4 s/步(solver 59%、
装配 28%);TET4 遗留臂 ~4 s/步;V1 纯热 144k 网格 ~8 s/步(PARDISO base,
phase23 未开,为下一个免费提速点)。

## 5. 距离"真实可用/算得足够准/可发表"的评估

**剩余工作与时间估计**(以下为估算,前提:当前节奏、无新病态暴露):

| 阶段 | 内容 | 估计 |
|---|---|---|
| 金标再基线 + c3d8 金标 | 主线确认两处语义变化→采纳确定性对 | ~1 天 |
| L0 冒烟(109k,N=50) | 全链贯通 + XY 路径文件落地 | 2–4 天 |
| L1 纯热 + 发射率括号(D-12) | 两个极端运行,2 K 层间判据 | 3–5 天 |
| D-11 两循环门试验 + 15 运行 T_cut×N 矩阵 | 单腿周期子域,冻结 T_cut 与 N | 1–2 周 |
| L2(980k,N=10)热-力 | 性能决策点:phase23 转正,视 profile 定 GPU 装配 | 1–2 周 |
| L3 全高对照 + CMM 11 脊挠度曲线 | 冻结参数单次(或少次)运行 + 分析 | ~1 周 |
| V2 立方 RS 对照(与 L3 并行) | 工作区已就绪,热门→力门 | ~1 周(并行) |

**合计:约 6–9 周到 L3 对照结果**;瓶颈项是 T_cut×N 矩阵(15 运行)与
L2 规模的性能表现。

**"算得足够准"是结果不是承诺**:宪法禁止对 1.276 mm 实测挠度做任何标定,
T_cut×N 只能靠收敛研究冻结(D-11 的 freeze-or-publish-band 出口)。已有的
量化证据支持谨慎乐观——热链在熔池尺度打到测量精度(V1 深度 −0.5%)、
力学链的两大病态(锁定、悬空跨)已各自修复并有指纹/幅值证据——但
σy>773 K 外推和 T_cut 语义是文献中公认的最大不确定源,CMM 对照落点
无法预知。

**可发表性**:即使 L3 对照不落带,材料也已构成两篇候选:
(a) 方法学论文——零标定纪律 + 偏差登记册 + 验证塔(基准→金标→能量台账→
熔池三角→RS 对照)的完整证据链,V1 三角与四处 Balbaa 转录陷阱
(Fig 1 粉末曲线 2x、Eq 14+15 孔隙率双计、[49] 出处断裂、Eq-11 符号)
本身即是可复现性贡献;(b) 若 L3 落带,AMB2018-01 验证论文主线成立,
V1/V2 作为 solver verification 章节。从 L3 出结果到可投稿初稿,
估计再加 **3–4 周**写作与图表;即总计 **约 2.5–3.5 个月**到首次投稿,
置信度中等(主要风险:T_cut×N 收敛不动点不存在 → 需按 D-11 的
publish-band 出口改写故事,时间不变,结论定位变)。
